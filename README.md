# 📊 Sales Dashboard Project

This project is a basic **Sales Dashboard** created using **Power BI** as part of a beginner-level data visualization task. It uses sample sales data to analyze trends across products, regions, and time.

---

## 📌 Dashboard Features
- **Line Chart**: Visualizes monthly sales trends.
- **Bar Chart**: Compares sales by region.
- **Donut Chart**: Shows distribution of sales by category.
- **Slicer**: Allows filtering by Region or Category.
